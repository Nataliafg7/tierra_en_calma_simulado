# Sensor y Datos - Monitoreo de Lecturas

## Actor
Usuario autenticado de Tierra en Calma.

## Objetivo
Visualizar los datos de temperatura y humedad en tiempo real y consultar el historial de lecturas.

## Tareas
- Iniciar sesión en la plataforma.
- Acceder a la vista de monitoreo de una planta específica.
- Verificar las lecturas actuales.
- Consultar el gráfico histórico.

## Interacciones
- El usuario navega a la vista de detalles de la planta.
- El sistema consulta los datos más recientes del sensor.
- El sistema renderiza un gráfico con el historial de lecturas.

## Resultados esperados
- Visualización clara de temperatura (ej. "25.0 °C") y humedad (ej. "60.0%").
- Renderizado correcto del gráfico de historial.
