# Simulador de Flujo Completo - E2E Integral

## Actor
Usuario final del sistema Tierra en Calma.

## Objetivo
Validar la integración de todos los módulos: Login, Selección de Planta, Telemetría y Verificación.

## Tareas
- Iniciar sesión con credenciales válidas.
- Navegar al listado de plantas.
- Seleccionar una planta para monitoreo.
- Verificar datos en tiempo real.
- Realizar verificación de condiciones.

## Interacciones
- El usuario completa el flujo de autenticación.
- El usuario navega por las diferentes secciones de la SPA.
- El sistema mantiene el estado de la sesión y carga los datos correspondientes en cada vista.

## Resultados esperados
- El usuario puede completar todo el recorrido sin errores.
- Confirmación final de "Verificación exitosa".
