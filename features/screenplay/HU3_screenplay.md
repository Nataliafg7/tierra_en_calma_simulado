HU3 - Inicio de sesión

Actor:
Usuario registrado de Tierra en Calma.

Tarea:
Iniciar sesión en la plataforma.

Interacciones:
- Ingresar correo electrónico.
- Ingresar contraseña.
- Presionar el botón de inicio de sesión.
- Validar mensajes del sistema.
- Verificar redirección según el tipo de usuario.
- Validar almacenamiento en sesión.

Preguntas:
- ¿El sistema valida campos obligatorios?
- ¿El sistema autentica correctamente al usuario?
- ¿El sistema redirige al administrador a /admin?
- ¿El sistema redirige al usuario a /mis-plantas?
- ¿El sistema guarda la sesión correctamente?
- ¿El sistema maneja errores del backend?
- ¿El sistema evita navegación cuando falla el login?
