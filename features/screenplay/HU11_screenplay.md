HU11 - Visualización de plantas registradas

Actor:
Usuario autenticado de Tierra en Calma.

Tarea:
Visualizar y gestionar sus plantas registradas.

Interacciones:
- Ingresar a la vista de mis plantas.
- Validar sesión del usuario.
- Consultar plantas registradas.
- Visualizar lista de plantas.
- Navegar entre plantas.
- Monitorear planta.
- Navegar a registrar nueva planta.

Preguntas:
- ¿El sistema valida sesión activa?
- ¿El sistema carga correctamente las plantas?
- ¿El sistema maneja lista vacía?
- ¿El sistema maneja errores del backend?
- ¿El sistema permite navegar a registrar plantas?
- ¿El sistema valida plantas inválidas?
- ¿El sistema maneja correctamente el carrusel?
