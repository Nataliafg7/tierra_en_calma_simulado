# Contacto - Formulario de Contacto

## Actor
Usuario interesado en el proyecto Tierra en Calma.

## Objetivo
Enviar un mensaje de contacto para recibir más información sobre el monitoreo de plantas.

## Tareas
- Acceder a la página principal.
- Localizar el formulario de contacto.
- Diligenciar nombre, correo y mensaje.
- Enviar el formulario.

## Interacciones
- El usuario ingresa sus datos en los campos correspondientes.
- El usuario hace clic en el botón "Enviar Mensaje".
- El sistema valida que los campos no estén vacíos.
- El sistema muestra una alerta de confirmación tras el envío exitoso.

## Resultados esperados
- El formulario debe reiniciarse después del envío.
- Se debe mostrar el mensaje: "fue enviado correctamente".
