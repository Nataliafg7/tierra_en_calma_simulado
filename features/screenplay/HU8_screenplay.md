HU8 - Consulta del banco de especies

Actor:
Usuario de Tierra en Calma.

Tarea:
Consultar el banco de plantas disponibles.

Interacciones:
- Ingresar a la vista de registrar plantas.
- Solicitar el banco de especies al sistema.
- Procesar la lista de plantas.
- Visualizar las especies disponibles.

Preguntas:
- ¿El sistema carga correctamente las plantas?
- ¿El sistema construye el mapa de identificadores?
- ¿El sistema normaliza los nombres de plantas?
- ¿El sistema maneja errores del servidor?
- ¿El sistema maneja respuestas vacías?
